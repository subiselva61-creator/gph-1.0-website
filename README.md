# Green PowerHouse Website

Premium investor-facing frontend for [gph.energy](https://gph.energy) — climate-finance advisory connecting international capital with green hydrogen projects in the Global South.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion
- next/font (Geist + Instrument Serif)
- lucide-react

## Routes

| Path | Page |
|------|------|
| `/` | Home |
| `/our-proposal` | Our Proposal |
| `/market-insights` | Market Insights |
| `/contact-us` | Contact form |

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

Deploy on Vercel with the default Next.js settings.
